# Contribution Guidelines

We welcome contributions to repositories in the `Org-DevOps-Tools` organization.

## Before contributing

1. Search existing issues and pull requests before opening a new issue.
2. For substantial changes, open an issue first to explain the problem and proposed approach.
3. Read the target repository's README and local contributing supplement before making changes.
4. Never commit passwords, tokens, private keys, signing material, or other secrets.

## Pull requests

- Use a focused branch and a clear description of the change.
- Keep commits small and independently understandable.
- Add or update tests and documentation where appropriate.
- Run the target repository's required checks before requesting review.
- Describe known limitations, security implications, and deployment impact.
- Respond to review feedback and rerun affected checks after changes.

Repositories may add language, framework, release, or deployment-specific instructions in a local `CONTRIBUTING.md` or linked supplement. The local supplement extends this policy; it does not silently weaken it.

## Code of Conduct

Participation is governed by the [organization Code of Conduct](CODE_OF_CONDUCT.md).
